I thought about doing HolyC as a homage to Terry Davis, but it would need to be done in TempleOS to stay accurate, and would be way harder to do without his knowledge of the system. Sure, I stated I'm doing this to challenge myself, but I'm not trying to challenge my time and nerves — I'm just challenging my programming knowledge and insight into widely used and researched programming paradigms. So, unfortunately, I won't be doing HolyC.
